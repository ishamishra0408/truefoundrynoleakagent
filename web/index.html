Architecture

One deterministic policy node, in front of GitHub's official MCP server.

The agent reaches GitHub only through NoLeak. Reads pass; writes are inspected. Values NoLeak brokers from the private zone are tainted; any public write carrying one — verbatim, whitespace-split, zero-width, or base64/hex-encoded — is denied. The full source diagram is architecture.d2 (D2). The replay above is that architecture, live.

Rule A — provenance (taint)

Every value returned by read_deploy_secrets is tainted for the session. A public write carrying any 8-char window of it (after normalization + base64/hex decode) is DENIED. No model in the decision.

Rule B — secret shape

Narrow fallback for values NoLeak never brokered: AWS key id, a 40-char non-hex mixed-case run, the canary token. Git SHAs, env-var names, URLs and the word “canary” all pass — 0% false positives.
